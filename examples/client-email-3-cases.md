# Synthetic B2B/customer mail — three editorial use cases

Use the known facts in the scenario only; placeholders are **not** invented personal data. This demonstrates tone and decision structure, not measured reply rates.

## 1. Japanese client document request
**Provided:** sender and client already work together; need current draft of a shared document; no deadline.
**Before:** `資料の最新版を送っていただけますと幸いです。` (lacks context)
**After subject:** `資料の最新版ご共有のお願い`
**After body:**
```
いつもお世話になっております。
進行中の案件について、資料の最新版をご共有いただけますでしょうか。
お手数をおかけしますが、どうぞよろしくお願いいたします。
```
**Review:** no made-up due date or meeting; sendable only after adding true recipient/sender names. Remove `進行中の案件` if context is not shared or subject references wrong project.

## 2. First contact — avoid fake relationship
**Provided:** cold inquiry to a prospective partner, asking if a collaboration proposal can be sent. No referral.
**Before:** `いつも大変お世話になっております。以前からご縁をいただき…`
**After subject:** `協業のご相談について`
**After body:**
```
初めてご連絡いたします。
協業についてご相談したく、ご連絡いたしました。
ご関心がございましたら、概要資料をお送りしてもよろしいでしょうか。
どうぞよろしくお願いいたします。
```
**Review:** polite without fictitious prior connection; separate advertising-email rules may apply depending on actual circumstances.

## 3. Customer update — do not promise completion
**Provided:** customer reported an issue; sender is verifying it, no completion date known.
**Before:** `本日中にすべて解決いたします。`
**After subject:** `お問い合わせ内容の確認状況について`
**After body:**
```
お問い合わせいただいた件について、現在状況を確認しております。
確認ができ次第、あらためてご連絡いたします。
どうぞよろしくお願いいたします。
```
**Review:** preserves only actually verified "currently checking". Do not add guaranteed resolution, apology for unverified fault or invented schedule. A real sender should provide contact/identity and contact policy as appropriate.
