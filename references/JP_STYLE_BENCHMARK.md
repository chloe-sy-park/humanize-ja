# 日本語「書き手の信頼」をつくる9事例 — 定性文体ベンチマーク

**期間:** 主に2025〜2026年に公開された日本語記事9本（リサーチ日2026-10-25）。**方法:** 各公開ページの冒頭・本文抜粋、見出し構成、事実の提示方法を編集者視点で観察。**対象範囲:** 創業者の自己記述3 / マーケティング実務者の説明3 / 日本ビジネスメディア記事3。**重要:** 単純無作為抽出ではない。反応数や業績の因果推定、AI文章かどうかの判定、日本人全体に対する一般化はできない。長文原稿のコピーはしていない。

## A. 日本スタートアップ創業者・経営者: 声と自己限定

### A1. Kei Nagai / アダコテック代表 — 代表交代をめぐる個人視点
- **原文:** https://note.com/kei_nagai/n/nae84cc3dc2a2 (2026-09-25)
- **実際に確認した手がかり:** 「久しぶりのnote」という個人的再開、代表交代という特定の出来事、就任以前は普通の社員だったという自己位置付け、経過年数。
- **文体の機能:** 役職の大きさより『自分に突然起きたこと』を入口にする。日付・期間が読者に文脈を提供する。人物像の過度な演出不要。
- **スキルへの変換:** 書き手本人の事件が確認できる場合のみ一人称の「具体的な場面 → 当時の立場 → 考え」を使う。外部会社について調べた内容を「私が経験した」に書き換えない。

### A2. 武田勇 / オヤシル代表 — 振り返りと教訓を分離
- **原文:** https://note.com/oyashiru_tkdism/n/n8bece2782e69 (2026-05-01)
- **手がかり:** 第2期終了という明確な時点、`Good` と反省、継続・展開案件、ピボット検証など具体的項目と、その後の説明。
- **文体の機能:** 「成果ばかりを並べる」のではなく、振り返りの評価基準が明確。内部数値をむやみに盛らない。
- **スキルへの変換:** 既に原文にある良かった点/教訓を分けて伝える。根拠がない失敗や伸び率を追加しない。

### A3. 籔井健一 / グリッジ代表 — 成長と不安の非対称性
- **原文:** https://note.com/gridge_inc/n/n7d40dda16003 (2025-12-25)
- **手がかり:** チーム拡大や非日本語話者の増加といった具体的な変化、社内伝達で感じた負荷・思考の変化について一人称で記述。
- **文体の機能:** 組織変化に対して何が難しかったかを丁寧に説明する。成功の宣言→抽象的学びではなく、観察と感情が連動する。
- **スキルへの変換:** 一人称の不安・葛藤は実際に提供されたときのみ保持。ビジネス上の問題の原因を特定できなければ推測に留める。

**創業者モードの編集ルール:** 原文が持つ「いつ/何が/誰に/どんな認識の変化」がある部分を残す。小さな不格好さ・素直な迷いは許容。ただし `正直` `〜なんですよね` を機械的に投入しない。創業者を全員同じ書き手にしない。

## B. マーケティング実務者: 実務用語を抽象論にしない

### B1. よそおいさん — KPIレビューの具体的な困り事から始める
- **原文:** https://note.com/yosooi/n/n9934afb8dc3c (2026-09-07)
- **手がかり:** 表示回数、クリック率、滞在時間、問い合わせ数の動きがそれぞれ違う場面を提示。問いと会議での判断困難を描く。
- **文体の機能:** 抽象的な「データドリブンが重要」を避け、現場で判断できない状況を説明。
- **スキルへの変換:** KPIをひとつに整える前に、原稿が比較している複数指標とその限界を維持。読みやすいが証拠のない事例への置換はしない。

### B2. 小川貴史 / マーケティングアナリスト — 数値・方法の配置
- **原文:** https://note.com/ogataka/n/n409e67ee1f2a (公開2026-06-05、記事には2026-09-18更新記載)
- **手がかり:** CPA 5,882円という数値、MMM手法、対象事例、結果を整理。1つの指標が示すのは対象ケースの話。
- **文体の機能:** 指標の名称と測定/導出の文脈を結ぶ。数値が断定的成功談として独り歩きしないよう読む必要がある。
- **スキルへの変換:** 主張の母集団、期間、計測定義を維持。実験結果の相関を因果確定に変えない。数値や出典を落とさない。

### B3. Web集客の案内人 — 自身の数字の使い方を見せる
- **原文:** https://note.com/marketer_cmo/n/n38d182640e15 (2026-08-30)
- **手がかり:** 投稿数の自己申告、成果と未達の両方を共有する宣言、数字をどう解釈するかという問題設定。
- **文体の機能:** 単なる実績アピールではなく、読者に検討過程を説明する。改行の多さは投稿スタイルであってAIの証拠ではない。
- **スキルへの変換:** 作者の元の改行と慎重さを尊重。『数字が上がった』から『成功した』に勝手に変えない。

**マーケター・モードの編集ルール:** `施策 → 観測値 → 解釈 → 限界/次の検証` を使う。ただし実際に書かれた情報のみ。ROAS/CPA/CTRなどの用語・期間・分母を無断変更しない。見出しで数字を強めない。

## C. 日本ビジネスメディア: 公的で読みやすい記述

### C1. MarkeZine — 機能・背景・発言の帰属
- **原文:** https://markezine.jp/article/detail/48587 (2025-05-09)
- **手がかり:** 冒頭で市場課題の背景を説明し、プラットフォーム名、企業名、取材対象、セッションの内容に帰属を与える。
- **文体の機能:** 記事の目的・発言源を先に特定し、本文で詳述する。中立な第三者視点と技術用語の正確さ。
- **スキルへの変換:** ニュース/取材記事に書き手の主観・驚きを挿入しない。発言元と事実のレベルを混ぜない。

### C2. AdverTimes / 宣伝会議 — 問題・調査方法・数値を接続
- **原文:** https://www.advertimes.com/20260827/article554035/ (2026-08-27)
- **手がかり:** エンゲージメント調査の実務上の問題、対象人数・割合、専門家コメント、改善行動の関係が記述される。
- **文体の機能:** 標語的な「成果につなげるべき」より、誰の調査で何人の回答か、誰の提言かを明らかにする。
- **スキルへの変換:** 調査対象と結果・発言者の帰属を分け、見出しに条件や観測上の制約を反映。

### C3. 東洋経済データラボ — 分析対象・手法・主張の範囲
- **原文:** https://datalab.toyokeizai.net/Analysis/20260401000002 (2026-03-31)
- **手がかり:** 企業統治・労使関係と人材管理の分析について、対象データやパネル分析という方法を示す。
- **文体の機能:** 論점を先に置き、研究対象と手法により読み手がどこまで言えるかを判断できる。
- **スキルへの変換:** 出典・調査方法・対象範囲の記述を「柔らかい自然な日本語」にするために切り捨てない。

**メディア・モードの編集ルール:** 第三者・常体寄りの明晰な日本語を基本に、主語・引用の帰属・根拠・条件を保持。疑問形や私語、会話調の差し込みは原稿のジャンルに沿う場合のみ。

## 横断的な観察と反証
| 観察した書き方 | 見られた文脈 | やってはいけない一般化 |
|---|---|---|
| 個人の失敗/転機がある導入 | 一部創業者 note | 全創業者に失敗談が必要 |
| 数字+分母/測定の前提 | 一部マーケター・専門メディア | 数字を増やせば信頼獲得 |
| 丁寧語と強い/弱い文末の混在 | 個人発信 | 「〜なんですよね」が万能 |
| 複数の小見出し・箇条書き | メディア・実務記事 | 箇条書き=AIまたは人間 |
| 結論を先に示す | ニュース・報告書 | 個人エッセイまで結論先行 |

## 編集パターンへの落とし込み（オリジナル、原문引用ではない）
- **創業者例:** 対象: 当人が経験した状況が原文にある時 → `「何をしたか」 → 「予想と違った点」 → 「今も判断がつかない点」`。全3要素の入力がなければ構成しない。
- **マーケター例:** `当初の目的 → 既存の指標の変化 → 解釈の限界 → 次の確認事項`。客観データと個人の仮説を分離。
- **専門メディア例:** `主題/ニュースの事実 → 関係者と発言の帰属 → 根拠・条件 → 背景`。感想を挿入しない。

**結論:** 自然な日本語の基準は汎用的な「人間味」の量ではなく、**媒体に合う信頼の示し方**によって変わる。
