# Optional generic profile: Japan-facing founder writing

This is a **channel guide**, not a claim that all Japanese founders write alike and not a specific person's identity. Apply only if requested or absent a real author sample and founder-channel is clearly intended.

- Main register: readable です・ます for a public business note; accept 常体 if author supplied it.
- Preferred evidence: actual decision, timeline, product/customer observation the author verified, uncertainty where real.
- Avoid: forced vulnerability, performed modesty, fake founder struggle, fake customer conversation, aspirational slogans, generic `挑戦の連続でした` endings.
- Voice: direct, thoughtful, not salesy; write for the intended audience instead of copying named authors.
- If real author samples exist, replace these defaults with user-specific habits without assigning a nationality or biography.
