# v1.2.0 リリースノート（公開用草案）

## 概要

日本語の文章を、事実・著者の語調・媒体に合わせて推敲するAgent Skillです。日本のマーケティングコピー、広告、ビジネスメール向けチェックを備え、商品の効能・比較・価格・注記を文章の自然さとは別に確認します。

## この版の変更点

- ブランド固有の比喩、短い言い切り、命令形などをまずKEEPとして評価するプロトコル
- 日本の化粧品・薬用化粧品広告で気を付ける数値、効能、表示条件の補助監査
- 日本の公式ブランドコピー20件の定性レビュー、公式公開文10件とAI試作文10件の非ブラインド比較
- 日本語のGitHub README、インストールガイド、使用例集、FAQ、CIと公開前確認表

## 限界

研究用ケースは小規模かつ非ブラインドで、効果・著者推定・法的適法性を検証するものではありません。自動スクリプトの警告は人による確認を前提とします。

## インストール

[インストールガイド](INSTALL_JA.md)に従ってフォルダを配置してください。GitHubの公開URLは実際にリポジトリを公開した後に案内してください。
